Five Official CityU Rules

Encoded directly as data in src/cityugpa/scales/cityu.json — every edge case matches official university policy.

Source: CityU ARRO Policy
1
Truncate at 2 decimals, never round
Computed via math.floor(x * 100 + 1e-9) / 100.
ARRO: 41.0 ÷ 12 = 3.41
Generic calculators round up to 3.42
2
Failed courses (F) count as 0.0 in GPA
Earns 0 credit units toward graduation, but stays in the GPA denominator.
CS2613 F stays in 7 CU denominator
Dropping F inflates CGPA to 3.50
3
Retakes keep only the latest attempt
Earlier attempts remain on record, while CGPA uses only the most recent term.
CS2310: 2026A B+ replaces 2025A C+
Averaging both drops CGPA to 2.79
4
Starred grades (A+*) are fully excluded
Contributes neither to GPA calculation nor to earned graduation credit units.
A+* = 0 CU earned, 0 CU in GPA
Generic tools count it as A+ (4.3)
5
Non-graded marks separated by credit rule
P / TR earn credit only; Z / IP / I / X / WD / AU earn neither.
P = +3 CU earned, 0 pts; Z = 0 CU
Generic tools miscount as 0.0

Problems Encountered & Solutions

Four concrete engineering issues we caught during development and how each was resolved in code.

Floating-Point Truncation Drift

Issue: Binary float noise made floor(3.41 * 100) return 340, silently losing 0.01.

Fix: Applied math.floor(x * 100 + 1e-9) / 100 to absorb IEEE-754 noise while still strictly truncating 3.4166… to 3.41.
Starred Grades (A+*) Mishandling

Issue: Trailing asterisks were initially stripped or treated as regular A+ credits.

Fix: Preserved * in parser.py; scale.py returns counts=False and can_earn_credit=False.
Broken Excel CSV Encodings

Issue: GBK/UTF-16 exports or malformed rows could crash with raw tracebacks or silently skip courses.

Fix: parser.py enforces UTF-8 with an actionable “Save as CSV UTF-8” hint and reports every bad row by exact line number (exit code 1).
Offline & Packaged Data Paths

Issue: Relative paths to cityu.json broke outside the repo, and PATH issues tripped up beginners.

Fix: Packaged cityugpa.scales as a subpackage loaded via importlib.resources.files("cityugpa.scales") (defaulting load_scale() to "cityu") and documented python3 -m cityugpa.cli.
